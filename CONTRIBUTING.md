# Contribuindo com o QueueCare

1. Crie uma branch para cada funcionalidade (`feat/`, `fix/`, `test/`, `docs/`, `infra/`).
2. Mantenha os commits pequenos e descritivos.
3. Escreva e execute os testes pertinentes.
4. Abra um Pull Request explicando as alterações e os testes executados.
5. Aguarde a revisão técnica.
6. Não faça merge sem CI verde e aprovação explícita do Matheus.

Consulte [`CLAUDE.md`](CLAUDE.md) e [`docs/regras.md`](docs/regras.md) antes de implementar funcionalidades.
